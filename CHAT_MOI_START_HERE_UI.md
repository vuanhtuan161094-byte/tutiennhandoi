# UI HANDOFF — V140

Backend canonical baseline is `1.40.0-alpha.24.0` / Tu Luyện V2.

The cultivation screen must not reintroduce retired V129 concepts. Player-facing cultivation is limited to:
- current realm and Tu Vi progress;
- concrete Tu Vi / 15s and expandable source provenance;
- Bế Quan bank and concrete expected Tu Vi;
- Thương Thế;
- Thọ Nguyên or Đạo Suy;
- deterministic Thăng Cảnh, or Thiên Kiếp where the realm explicitly requires it.

Use `UI_UX_PRODUCTION_DIRECTION_V1.md` for general art/layout direction, but V140 gameplay contract overrides any older wording in UI notes.
