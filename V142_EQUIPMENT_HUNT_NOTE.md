# V142 Equipment × Hunt — working note

User lock 2026-09-07:

- Hunt region of rank R can drop equipment fragments of rank R, but same-rank fragments must be rare.
- The same region also drops lower-rank equipment fragments.
- One finished item costs 50 fragments of its own rank.
- 3 fragments of rank N refine into 1 fragment of rank N+1.
- Therefore Luyện Khí item = 50 Luyện Khí fragments = 150 Phàm-fragment equivalent.
- Sáng Thế Chủ item = 50 Sáng Thế fragments = 1,143,839,622,748,050 Phàm-fragment equivalent.
- Finished equipment must not drop directly from Hunt in the V142 runtime target.
- 6 Y Trang sets grow long-run/raw combat stats; 4 Trang Sức sets focus bounded/capped utility stats.

Current implementation lives on a temporary bootstrap branch until runtime integration and QA closure pass.
