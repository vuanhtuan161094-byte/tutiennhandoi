## Findings from the tested pilot

1. A clean, transparent character reference and an independent motion source are separate inputs to Wan2.2 Move mode. The current AVI is suitable as a proof motion clip, but its 8 FPS arm sweep is not a good semantic hand-gesture demonstration.
2. A single shoulder pivot preserves feet/root position cheaply and exports consistently, but it cannot reproduce elbow bend, wrist turn, finger seals, layered sleeve overlap or hair motion. The measured frame sequence therefore passes packaging and root stability but remains a partial Cast animation.
3. RIFE may increase frame count after a good result. It cannot create a missing hand sign or correct an identity drift.
4. The official Wan2.2 guide lists a 14B model plus VAE, CLIP vision, text encoder and custom nodes. This makes the lack of GPU and model weights a concrete blocker to running B locally, rather than a reason to substitute a static image and call it AI animation.
5. The existing video-to-Godot pipeline is useful downstream, after a generated clip is accepted. It does not itself make a character rig or create semantic motion.
