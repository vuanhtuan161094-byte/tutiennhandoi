## Milestone order

1. **A1 candidate proof (this pilot):** image layers, rig loop, Godot resources and candid evidence; done with gesture limitations recorded.
2. **A2 articulated Cast:** close AP-01 before using this as a benchmark for the 10-skill pipeline.
3. **B1 GPU experiment:** run AP-03 on approved hardware; no local substitute is counted as Wan output.
4. **Comparison gate:** AP-04 and AP-05; choose a primary workflow only after comparable previews exist.
5. **Ten-skill pilot:** AP-06 with representative actions, then AP-07 on supported device class.
6. **Production decision:** AP-08 is separate and requires user approval; none of the candidate work silently changes gameplay, balance, saves or production art.
