## Scope and actual output

ART-01A V2 is a source-image-based cutout rig, **not AI-generated separate full-body frames**. It uses an arm-free edited Ngự Khí heroine master, normalized source art for both upper arms, forearms and independently controlled hands/wrists, and two discrete hand-seal assemblies. It also retains three separable Ngự Khí treasures as source art without combat-event wiring in this slice.

The user-supplied original character-design image was used for facial identity: a localized face-pixel patch (eyes/nose/lips/skin) is composited using +20/-19 pixel alignment and 4.5px feather. **This does not prove full pixel identity**; user visual approval remains required. Edited master preserves long dark hair, ornate purple/gold costume, gold heels, removes dangling sleeve drapes, and adds black fishnet stockings.

The standalone Godot candidate consists of a Node2D Shoulder → Elbow → Wrist hierarchy per arm, Sprite2D part assets, and an `AnimationPlayer` with one-shot (non-looping) tracks. Playback uses the same deterministic JSON joint data as the Python-rendered QA GIFs. Cast phases: **prepare → raise → seal → command → recover**.
