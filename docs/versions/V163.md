# V163 — Pháp Bảo / Chí Bảo Runtime Authority

Status: ACTIVE
Baseline: V162 CLOSED / LOCKED
Canonical implementation: `main`

## Objective

Consolidate Pháp Bảo / Chí Bảo runtime ownership without changing locked gameplay balance.

The current player-facing system is Collection-based (`artifact` / `relic` inside `collectionV12316`) with V12326 as the public Collection progression authority. A separate legacy `state.artifacts` structure still exists for compatibility/history and has real downstream consumers, so it must not be deleted blindly.

## Authority map after B1

- Player-facing Pháp Bảo ownership/progression lives in `state.collectionV12316.items`.
- Equipped Pháp Bảo authority is `state.collectionV12316.activeArtifactIds`.
- Player-facing progression mutations enter through V12326 Collection methods established by V162; the lower Session implementation may still use V12325 names as compatibility implementation.
- `dist/core/artifact-v88.js` is the live Pháp Bảo/Chí Bảo combat adapter and layers V150/V151 behavior over `artifact-v149-base.js`.
- `applyCollectionEconomyToEntityV12325()` is the current Collection composition boundary and calls `applyCollectionToEntityV12316()` once.
- `SimulationSession.personalCombatEntityForState()` deliberately does not apply legacy `state.artifacts` as direct Pháp Bảo combat power; it composes Collection power once, then may still use `state.artifacts` through Integration/history-derived behavior.
- Chí Bảo ownership/progression lives inside the Collection economy state and its active authority is `collectionV12316.economyV12325.activeRelicId`.
- Chí Bảo remains a separate one-slot combat-law system and does not consume a Pháp Bảo slot.
- `dist/core/artifact.js` / `state.artifacts` are required compatibility/history state, not a second player-facing loadout. Verified responsibilities include nourishment, Khí Linh awakening, ownership years, battle history, lost/recovered history and Integration/reincarnation consumers.
- Save/restore preserves `state.artifacts` and `state.collectionV12316` as separate cloned channels; B1 found no authority merge.
- No legacy artifact source was deleted in B1 because no surviving legacy module was proven wholly dead.
