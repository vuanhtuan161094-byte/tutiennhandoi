# V177 — Session Action Identity Runtime Authority

Status: **CLOSED / LOCKED**

## Finding

`SimulationSession.snapshot()` persisted `actionIndex` and EventHistory independently. `instantRetreatV140()` uses `actionIndex` both in its deterministic RNG lane and in the durable event ID `retreat.v140.<lifeId>.<actionIndex>`, then advances the index. A stale/lowered saved `actionIndex` could therefore reuse an already-consumed retreat serial after restore while the valid retreat history still proved that serial had already run.

## Locked authority

- A validated canonical V140 Retreat history event is durable lower-bound evidence for the next session `actionIndex`.
- Restore may raise a stale/lowered action index to `usedSerial + 1`.
- Restore never lowers a legitimate higher saved `actionIndex`.
- Malformed or unrelated history IDs cannot forge action-index authority.
- The repair is contained in the already-eager `session-restore.js`; no new eager module is introduced.
- No reward, rate, RNG formula, balance or pacing value changed.
