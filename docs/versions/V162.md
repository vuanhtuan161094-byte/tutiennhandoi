# V162 — Runtime Authority Consolidation

Status: ACTIVE
Baseline: V161 CLOSED / LOCKED
Canonical implementation: `main`

## Purpose

Reduce duplicate/legacy runtime authority one subsystem at a time without rewriting locked gameplay algorithms or save state simply to make version names look newer.

## Scope

First subsystem: Collection / Vạn Tượng / collection progression.

Authority target:

- player-facing Gacha: V12326 only;
- player-facing collection progression API: V12326 namespace;
- V12325 progression engine may remain underneath until separately migrated;
- `collectionV12316` state may remain for save compatibility;
- legacy transport names are removed only after all live callers have moved.

## Phase status

### B1 — Collection/Gacha public authority — PASS

- GameplayFacade no longer exposes `collectionGachaV12316` or `collectionGachaV12325`.
- LocalGameApplicationApi no longer exposes `gachaCollectionV12316` or `gachaCollectionV12325`.
- V12326 Gacha remains live and continues spending the same Bound Jade wallet.
- Standalone transport already blocks both legacy Gacha actions.
- Internal Session compatibility methods remain because they are implementation detail and preserving `session.js` as the canonical source file avoids breaking unrelated locked structural tests.
- Dedicated gate: `qa/tests/v162-collection-runtime-authority-test.js`.
