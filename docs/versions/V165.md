## Scope

Audit and lock the live authority for Trang Bị / Set V142, including state, mutation, combat composition and save/restore compatibility. No balance redesign was authorized.

## Locked authority

- Canonical equipment state remains `state.equipment`.
- V142 progression uses `equipmentRankIndex` as its rank axis, with Enhancement capped at +15, authored Affix progression, and V142 Set engraving/resonance.
- V142 items do not use the retired Grade/Quality/Trait/Đạo Văn/Ngũ Hành Ngọc progression lanes as live power systems.
- V115/V128 Đạo Văn/Gem methods remain only for legacy equipment and explicitly reject `equipment.v142` items.
- V142 Set combat power is derived from equipped V142 item IDs through `equipmentSetPowerV142` and composed once by the equipment combat adapter.
- V116 legacy Set mechanics remain separate compatibility behavior for legacy equipment; V142 Set IDs are a distinct catalog.

## Fixes made

V165 found a real save/load authority gap: generic legacy normalization allowed a stale/tampered V142 item to retain fields that are retired for V142, and could also retain enhancement above the V142 +15 cap.

`normalizeCanonicalEquipmentAfterRestore()` now canonicalizes every restored `equipment.v142` item:

- Enhancement clamped to `0..15`.
- Transport-only `tier`, `grade`, and `quality` reset to neutral V142 compatibility values.
- Legacy `traitIds`, `daoInscription`, and `gemSockets` are cleared.
- Legacy/non-V142 Set IDs are removed; invalid resonance is reset.
- Valid V142 Set identity/resonance is preserved.
- Legacy equipment remains untouched and keeps its compatibility semantics, including its independent +20 enhancement cap.
