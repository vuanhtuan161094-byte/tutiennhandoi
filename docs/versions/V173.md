# V173 — World → Hunt Runtime Authority Consolidation

Status: **CLOSED / LOCKED**

## Objective

Close provable restore/runtime authority splits from World through Hunt without changing authored balance, rewards, rates, sources or sinks.

## Findings closed

1. **Orthodoxy territory split authority**
   - Runtime maintains both `orthodoxy.territoryIds` and `territoryOwnerByLocation` for the same territorial authority.
   - A mismatched restored save could let one orthodoxy count a territory for capacity/economy while the owner map assigned the same location elsewhere.
   - Restore now preserves only current-world territories whose list entry and owner mirror agree, deduplicates them, then rebuilds the owner map.

2. **Economy / Inventory malformed numeric state**
   - Live resource quantities, market stock/counters and economy lifetime counters are non-negative runtime quantities.
   - Restore now normalizes only impossible `NaN` / non-finite / negative values.
   - Valid positive balances and stock are preserved; V173 does not invent a cap or re-derive legitimate wealth.

3. **World opportunity replay authority**
   - Live opportunity settlement records monotonic claim evidence across the global claimed list, claim record and per-NPC claimed list.
   - Restore now unions valid surviving claim evidence so deleting only one mirror cannot make an already-accounted opportunity replayable.
   - Dangling/non-authored opportunity references are removed.

4. **World relationship identity and ranges**
   - NPC-NPC relationships use their canonical pair key; player relationships use `${lifeId}|${npcId}`.
   - Restore removes identity-mismatched/dangling rows, clamps authored `0..100` axes, repairs interaction counts and deduplicates player flags.

5. **Genesis active-world capacity**
   - Live creation is bounded by `genesisWorldCapacity()` derived from Immortal `creationEpochs` and `genesisAuthority`.
   - Restore now applies the same active-world cap. Excess active worlds are removed; extinct history is retained.

6. **Hunt first-clear / unlock split authority**
   - Hunt progression is mirrored by per-major clear/unlock state, aggregate floors and per-floor boss-win statistics.
   - Restore reconciles saved clear progress with surviving boss-win evidence, derives the next sequential unlock, repairs aggregate/selected/farm pointers and removes a stale active boss on a floor that is already cleared.
   - This prevents a single-lane save edit from replaying first-clear authority while another canonical mirror still records the boss win.

## Implementation

- Runtime repair lives in the already-eager `dist/core/save-stability.js` path through `normalizeCanonicalWorldToHuntAfterRestore(state, world)`.
- It is invoked by the existing `repairAdventureStateReferences(...)` restore flow.
- No standalone eager runtime module was added.
- The locked frontend performance threshold was not raised.

## Targeted proof

`qa/tests/v173-world-to-hunt-runtime-authority-test.js` proves 7 cases:

1. Orthodoxy territory requires list/owner agreement.
2. Impossible Economy / Inventory / Orthodoxy numerics are repaired conservatively.
3. Opportunity claim mirrors prevent single-lane replay.
4. World relationship identities and live ranges are canonicalized.
5. Genesis active worlds cannot exceed Immortal-derived capacity.
6. Hunt first-clear evidence repairs split clear/unlock authority and blocks stale boss replay.
7. Full `SimulationSession.restore()` applies V173 canonicalization before runtime consumers resume.

The first Fast attempt exposed only a test-fixture issue: `createPlayableAdventureState()` intentionally does not instantiate Hunt until Session initialization. The proof was corrected to use canonical `createEndlessHuntState()`; the runtime patch was not changed for that failure.

## Non-goals

V173 does **not** change:

- market price formulas or authored market stock behavior;
- legitimate positive inventory/economy balances;
- Orthodoxy income, capacity, war or relation coefficients;
- Genesis capacity formula;
- Hunt reward, drop, power, floor-count, farming or pacing formulas;
- any V160–V172 locked authority.
