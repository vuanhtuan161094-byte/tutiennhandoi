## Findings fixed

1. Character provenance placed Linh Căn V145 before stages that runtime applies earlier; the breakdown could diverge from combat.
2. Raw/% HP authored by Equipment/Collection could be overwritten by the final Alchemy compatibility pass or ignored by the old `physique × 20` consumer.
3. Legacy ArtifactState could re-enter combat indirectly through Integration despite Collection being canonical Pháp Bảo/Chí Bảo authority.
4. Accuracy/Mobility/Control Power/Resolve were live combat inputs but absent from the provenance surface.
5. Canonical QA exposed a V151 Sơn Hà Đồ threshold regression when synthetic legacy `maxHp` was treated as canonical materialized HP. The final marker-based authority fixes this without weakening the V151 test.
6. The old V163 assertion that legacy Artifact progression strengthens Integration is intentionally superseded by V168; legacy artifact history/archive behavior remains preserved.
