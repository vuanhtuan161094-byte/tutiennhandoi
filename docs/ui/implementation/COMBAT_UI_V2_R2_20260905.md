# Combat UI V2 R2 — Structural Redesign

## Evidence used
- Canonical V129 UI handoff.
- Locked combat reference image.
- User's real 390×844 capture after Combat Visual QA R1.

## Why R1 was not enough
R1 still inherited an app-like composition: bottom navigation remained visible, pre-fight showed battle-only skill/log chrome, and the Boss CTA divided the middle/lower battlefield. The result was technically clean but visually fragmented.

## V2 decision
Combat is now an immersive route-specific shell instead of a standard app tab.

### Pre-fight
Visible priority:
1. Encounter identity.
2. Enemy/player art.
3. Actor HP/resource truth.
4. One Boss CTA.

Hidden until battle:
- skill HUD,
- combat intelligence meters,
- compact combat log,
- companion/artifact extension HUD,
- duplicate floor/tool cluster.

### In battle / auto field
Visible priority:
1. Actors and VFX.
2. Actor HP/resource/status.
3. Read-only learned-skill cluster.
4. Bản Đạo/Ultimate meter.
5. One-line event ticker.

No manual-cast interaction was added.

## Shell change
`styles.css` hides the global bottom navigation only when `data-game-screen="hunt"`. Combat adds its own explicit exit control back to `dungeons` / Phiêu Lưu.

## Background defect
`assets/huntv2/backgrounds/wood.webp` contains baked text at the top: "Khắc: Thủy / Bị khắc: Kim". This is the clipped green text visible in the user's screenshot. It is not a DOM/CSS producer. R2 crops/zooms the asset to remove that text from the normal viewport.

This is a temporary production mitigation. A clean background without baked labels is the preferred final asset.
