## Visual rules

- Xianxia/manhua illustration is the primary visual language.
- The world/character occupies most of the screen; UI supports it rather than becoming dashboard walls.
- Deep blue/cyan atmosphere with warm gold progression accents.
- Dark translucent glass surfaces, thin ornamental borders, restrained glow.
- Hierarchy: hero/world first, progression second, controls third.
- Boss intel stays compact: identity, HP/phase, key stats, key skills/mechanics.
- Avoid full-screen text tables, dense admin panels and raw backend terminology.
- Godot effects should carry the game feel: aura, particles, sword qi, mist, hit flash, damage numbers and subtle camera feedback.

Concept art is not runtime proof. Each production screen must eventually be reviewed from the actual Godot runtime at the primary portrait viewport.
