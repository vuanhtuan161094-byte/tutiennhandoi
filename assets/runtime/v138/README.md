# Combat runtime assets v1.38

Live runtime policy as of v1.38.0-alpha.6:

- `icons/skills/**` contains the approved 80 canonical Dao skill icons.
- `combat-asset-manifest.json` is generated from the backend-aware contract.
- Player/Boss pose packs and raster FX are intentionally absent until true transparent production assets are authored and QA-approved.
- Design sheets and automatically cropped derivatives are not runtime assets.
- Live combat uses the clean full-art player fallback, beast-family boss fallbacks, and CSS/vector presentation primitives.
